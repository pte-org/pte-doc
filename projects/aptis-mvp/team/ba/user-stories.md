# User Stories — APTIS MVP (Host-Driven Exam Distribution)

## User Stories

### US-001

**As an** Admin, **I want** to log in with my email and credential **so that** I can securely access the Admin area.
**Priority:** Essential
**Effort:** S (1pt)
**Acceptance:** → acceptance-criteria.md

### US-002

**As an** Admin, **I want** to create new exam questions **so that** I can build content for tests.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-003

**As an** Admin, **I want** to edit and delete existing exam questions **so that** I can keep content accurate.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-004

**As an** Admin, **I want** to group questions into a named Exam **so that** I can assign a coherent test to students.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-005

**As an** Admin, **I want** to create a Host account and issue it a login credential **so that** a customer's manager can access the platform without sharing my own account.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-006

**As a** Host, **I want** to log in with the credential Admin gave me **so that** I can manage my organization's students and exams.
**Priority:** Essential
**Effort:** S (1pt)
**Acceptance:** → acceptance-criteria.md

### US-007

**As a** Host, **I want** to upload an Excel file with my student roster **so that** I don't have to create each student account manually.
**Priority:** Essential
**Effort:** L (5pt)
**Acceptance:** → acceptance-criteria.md

### US-008

**As a** Host, **I want** to see a row-by-row error report for my uploaded roster **so that** I can fix and re-upload only the bad rows.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-009

**As a** Host, **I want** to select an existing Exam and assign it to the students I just imported **so that** they all take the correct test.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-010

**As a** Host, **I want** to download an Excel file with the generated usernames and credentials for my imported students **so that** I can distribute login access to them.
**Priority:** Essential
**Effort:** L (5pt)
**Acceptance:** → acceptance-criteria.md

### US-011

**As a** Student, **I want** to log in with the username and credential I was given **so that** I can access my assigned exam.
**Priority:** Essential
**Effort:** S (1pt)
**Acceptance:** → acceptance-criteria.md

### US-012

**As a** Student, **I want** to view and answer my exam's questions **so that** I can complete the test I was assigned.
**Priority:** Essential
**Effort:** L (5pt)
**Acceptance:** → acceptance-criteria.md

### US-013

**As a** Student, **I want** to submit my exam **so that** my answers are recorded and cannot be changed afterward.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-014

**As a** Student, **I want** to see my score immediately after submitting **so that** I know my result right away.
**Priority:** Essential
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md

### US-015

**As an** Admin, **I want** to view a list of all Hosts with their student counts and exam-assignment status **so that** I can monitor platform usage at a glance.
**Priority:** Conditional
**Effort:** M (3pt)
**Acceptance:** → acceptance-criteria.md
