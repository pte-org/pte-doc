## Design Constraints

New admin page DTO excludes raw bearer token. Additive admin namespace avoids legacy String-path ambiguity and array-shape breakage. Secrets never enter React Query QueryCache/MutationCache, persistor, URL, success banner, access/body logs, or exported traces. Reuse existing refresh deduplication/one replay; no auth rewrite. Offset page ordering is deterministic, not a concurrent snapshot guarantee. No global Applications/Plans pagination architecture or invented latency SLO.

## Proposed HTTP contract

GET `/api/v1/admin/license-codes?page=0&size=25&status=ISSUED&planId=<UUID>&tenantId=<UUID>` returns200 `ApiResponse<PagedResult<AdminLicenseCodeSummary>>`; GET `/{publicId}` safe detail. POST `/lookup` `{code}` safe result200/404, POST `/{publicId}/reveal` no-store secret response200/404 with safe audit. UUID routes cannot overlap legacy bearer String routes. Forbidden403 does not look empty; malformed pagination400.

Selected old GET deprecation response410 uses existing ApiResponse error code/message; valid old successful shape is never replaced with PagedResult. Legacy overlap means explicit Partial security disposition. Add safe headers to all secret-bearing error/success responses, not only200. Redeem still accepts code in POST body and traces must redact it.
