## Proposed HTTP contract

POST `/api/v1/admin/license-codes`, header `Idempotency-Key: <UUID>`, body `{planId: UUID, codeExpiresAt: Instant|null}`. Fingerprint uses canonical UUID and null-or-UTC timestamp at microseconds; reject unsupported finer precision400 instead of silently rounding. Response `ApiResponse<LicenseIssueReceipt>`201/200. Same key+different canonical payload409; current authorization failures401/403. Only after no committed mapping exists: Plan absent404, inactive/non-EXAM409, invalid duration or nonfuture expiry422. No @Future controller validation may preempt an existing matching replay; malformed Instant/key remains400.

Existing POST `/api/v1/license-codes` delegates to identical mandatory-key protection and safe metadata response under the controlled client cutover; old missing-key client400 includes reload guidance. There is no unchecked legacy issue path. Existing tenant POST `/api/v1/license-code-redemptions` body `{code}` and activation response remain unchanged;404 unknown,409 redeemed/revoked,410 expired. Do not expose token in error text. Admin reveal is separate no-store POST defined06.
