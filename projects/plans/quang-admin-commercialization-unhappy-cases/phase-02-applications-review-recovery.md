Reject body `{reason}`; normalized blank/too long400 at HTTP validation and422 for direct service validation. Tenant-by-code lookup reuses the authorized tenant surface; if new HTTP lookup is required, phase01 proposes GET `/api/v1/admin/tenants/by-code/{requestedCode}` returning public tenant identity only. This is a nonsecret routing code, not a bearer credential. Confirm current existing tenant routes first.
