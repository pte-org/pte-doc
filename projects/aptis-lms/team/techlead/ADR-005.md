# ADR-005: Provider-neutral ports for storage, notifications and AI
**Date:** 2026-06-20
**Status:** Accepted

## Context
Cloud region and AI providers remain open decisions, while domain behavior must be implementable and testable now.

## Decision
We will define application ports for object storage, CDN URLs, email/push, STT and LLM scoring. Provider SDKs may appear only in infrastructure adapters selected by configuration.

## Consequences
### Positive
- OI-02 and OI-07 do not block domain/application development.
- Provider contracts can be tested with fakes and conformance suites.
- Provider migration does not rewrite use cases.

### Negative / Trade-offs
- Lowest-common-denominator abstractions can hide useful provider features.
- Every adapter needs explicit retry, rate-limit and error normalization.

### Risks
- Semantic differences between LLM/STT providers; enforce a canonical validated scoring response schema.
